# UPI Transaction Analytics Dashboard

## 📌 Project Overview

This project focuses on analyzing **UPI transactions** to identify transaction trends, customer behavior, payment patterns, and fraud-related insights. The data is analyzed and presented through an interactive dashboard using **Microsoft Excel**.

## 🎯 Objectives

* Analyze overall UPI transaction activity
* Identify successful and failed transactions
* Analyze transaction amounts and transaction types
* Understand device and network usage
* Compare transactions across banks, states, and merchant categories
* Analyze customer age-group behavior
* Identify fraud-related transaction patterns
* Study transaction activity by time and day

## 📊 Key Dashboard Insights

The dashboard includes visualizations for:

* Total Transactions
* Total Transaction Amount
* Successful vs Failed Transactions
* Transaction Type
* Merchant Category
* Device Type
* Network Type
* Bank-wise Transactions
* State-wise Transactions
* Age-group Analysis
* Fraud Transactions
* Hourly and Daily Transaction Trends

## 🛠️ Tools Used

* Microsoft Excel
* PivotTables
* PivotCharts
* Excel Dashboard
* Data Cleaning & Analysis

## 📂 Dataset

The project uses a **UPI Transaction 2024 dataset** containing transaction-level information such as transaction amount, transaction type, transaction status, merchant category, bank details, device type, network type, age group, location, and fraud indicators.

## 📈 Project Outcome

The dashboard converts raw UPI transaction data into meaningful visual insights, making it easier to understand **digital payment behavior, transaction performance, usage patterns, and fraud trends**.
